# Pi Companion (Antigravity)

Lets Pi 🥧 see which project you have open in Antigravity IDE so it can save **where you left off** to
`PiNotes/projects/<project>/CONTEXT.md`. Pi saves automatically when you close the project (or the editor quits),
and greets you with where you left off when you open it again.

- Status bar **🥧 Pi**: click it to open the last saved context.
- Commands: `Pi: Open Where I Left Off`, `Pi: Save Selection as Note`.

Talks only to the Pi app on `127.0.0.1:47615`. Nothing leaves your machine.
